사용 방법과 안심 안내

안심 PDF 도구 · 학교 업무용 PDF 웹앱

← 도구로 돌아가기

세 가지 약속

  1. 밖으로 보내지 않습니다. 이 웹앱에는 파일을 받는 서버가 없습니다. 모든 작업은 지금 쓰는 브라우저 안에서만 이루어집니다.
  2. 어디에도 저장하지 않습니다. 불러온 파일은 메모리에만 있다가 탭을 닫으면 사라집니다.
  3. AI가 학습하지 않습니다. AI 기능이나 외부 서비스를 쓰지 않으므로, 파일이 학습에 쓰일 경로가 없습니다.

브라우저의 보안 정책(CSP)으로 이 웹앱이 다른 사이트에 접속하는 것 자체를 막아 두었습니다. 도구 화면 아래 "안심 점검"에서 이 차단이 실제로 작동하는지 매번 확인합니다.

공문 첨부파일 만들기 (5단계)

  1. 불러오기 — PDF · 사진 선택을 눌러 PDF와 사진을 한꺼번에 고릅니다. 사진은 A4 PDF로 바뀝니다.
  2. 파일 정리 — "불러온 파일"에서 ▲▼로 파일 순서를 바꾸고, ✕로 필요 없는 파일을 뺍니다.
  3. 페이지 정리 — 페이지를 끌어서 순서를 바꿉니다(휴대폰은 길게 누른 뒤 끌기). 페이지를 눌러 선택하면 아래 도구 막대로 회전·삭제할 수 있습니다. 실수하면 되돌리기.
  4. 개인정보 가리기 — 가릴 페이지를 선택하고 ✎ 가리기·편집 → 가리기 도구로 상자를 그립니다.
  5. 저장 — 파일 이름을 정하고 PDF로 저장. 10MB가 넘으면 자동으로 줄이고, 그래도 넘으면 나눠서 저장할 수 있습니다.

기능별 사용법

개인정보 가리기
검은색·회색·흰색 중 고를 수 있습니다. 상자를 누르면 선택되고, 가운데를 끌면 이동, 모서리 손잡이로 크기를 조절합니다. 저장하면 가린 페이지는 그림으로 바뀌어 가린 곳 아래 글자가 파일에서 실제로 지워집니다. 저장 직후 자동으로 검사해 "✔ 개인정보 실제 제거 확인"을 보여 주며, 가린 이름이 다른 쪽에 남아 있으면 알려 줍니다.
글씨·도형 넣기
편집 화면의 도구 줄에서 글씨·사각형·원·선·화살표·형광펜을 고릅니다. 글씨는 넣을 곳을 누르면 입력 상자가 열립니다(엔터로 줄 바꿈). 글씨를 넣은 PDF는 한글 글꼴이 함께 들어가 약 0.75MB 커집니다.
10MB 미만 자동 압축
사진·스캔이 큰 페이지만 단계적으로 화질을 낮춥니다. 글자만 있는 페이지는 그대로 둡니다. 화질을 조정한 페이지는 그림이 되어 글자 선택·검색이 되지 않습니다.
이미지로 저장
선택한 쪽(없으면 전체)을 PNG 또는 JPG로 저장합니다. 여러 장이면 ZIP 하나로 묶습니다. 가린 영역과 글씨·도형도 그대로 반영됩니다.
편집 제한이 걸린 PDF
복사·편집이 막힌 PDF는 페이지를 그림으로 바꿔 넣습니다. 암호를 입력해야 열리는 PDF는 열 수 없으니, 암호를 해제한 뒤 불러오세요.

직접 확인하는 방법

  1. 인터넷을 끊고 써 보기 — 도구를 한 번 연 뒤, 와이파이와 데이터를 끄거나 랜선을 뽑고 작업해 보세요. 모든 기능이 그대로 동작합니다. 파일이 밖으로 나간다면 인터넷 없이는 동작할 수 없습니다.
  2. 네트워크 기록 보기 (PC) — 크롬·엣지에서 F12 → [네트워크] 탭을 연 채로 파일을 불러오고 저장해 보세요. 웹앱 자체 파일 외에 파일을 올리는 기록이 없습니다.
  3. 프로그램 코드 보기 — 이 웹앱의 코드는 모두 공개되어 있어 누구나 확인할 수 있습니다: github.com/jjoya0217/anshim-pdf

이 도구로도 막을 수 없는 것

  • 웹 호스팅(GitHub Pages)은 접속 기록(IP 주소, 접속 시각)을 남길 수 있습니다. 파일 내용은 포함되지 않습니다.
  • 컴퓨터에 설치된 브라우저 확장 프로그램이나 악성 프로그램은 화면 내용을 볼 수 있습니다. 업무용 PC의 보안 수칙을 지켜 주세요.
  • 저장한 결과 파일의 보관과 전달은 사용자의 책임입니다.
  • 휴대폰은 메모리가 적어 큰 파일(수백 쪽, 100MB 이상)에서 느리거나 멈출 수 있습니다. 큰 작업은 PC에서 하세요.

홈 화면에 설치하기

  • PC (크롬·엣지): 주소창 오른쪽의 설치 아이콘(⊕)을 누르면 프로그램처럼 쓸 수 있습니다.
  • 안드로이드 (크롬): 오른쪽 위 ⋮ → 홈 화면에 추가
  • 아이폰 (사파리): 공유 버튼 → 홈 화면에 추가

설치하지 않아도, 한 번 접속한 뒤에는 인터넷 없이 쓸 수 있도록 필요한 파일을 브라우저에 보관해 둡니다(프로그램 파일만 보관하며, 작업한 PDF는 보관하지 않습니다).
